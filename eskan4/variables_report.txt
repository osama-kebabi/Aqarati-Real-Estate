File: properties.html

- sampleProperties
  Purpose: In-memory array of property objects (id, title, city, region, property_type, rooms, price_num, price, images[], owner, status)

  Purpose: Helper that returns Arabic label for property types ('villa','house','shared')

  Purpose: Parses URL query string into an object

- populateLocationFilters()
  Purpose: Builds the city/region <select> options from sampleProperties
  Used in: properties.html (on DOMContentLoaded)

- debounce(fn, wait)
  Purpose: Utility to debounce input events
  Used in: properties.html (q input live filtering)

- renderProperties(list)
  Purpose: Renders property cards into `#propertiesGrid` based on provided list
  Used in: properties.html (called after filtering and initial load)

- applyFilters(updateUrl = true)
  Purpose: Reads filter inputs (q, city, region, type, rooms, min_price, max_price), filters sampleProperties, calls renderProperties, updates URL via history.replaceState
  Used in: properties.html (filter UI, debounced input, initial load)

- viewProperty(id)
  Purpose: Find property by id and call showPropertyModal(p)
  Used in: properties.html (card "عرض" button)

- showPropertyModal(p)
  Purpose: Builds and shows the modal overlay with image gallery, gallery nav, thumbnails, and property info (owner, rooms, status). Includes event handlers for prev/next, keyboard, touch swipe, thumbnail click, gallery click, and close.
  Key local vars inside modal:
    - overlay, modal, gallery, imgEl, imgs (array of image URLs), currentIndex
    - galleryNav, prevBtn, nextBtn, closeBtn
    - thumbs (thumbnail container), thumbEls (array of thumbnail elements), thumbHandlers (array of handlers)
    - onPrev/onNext/onGalleryClick/onKey/onTouchStart/onTouchEnd
  Used in: properties.html (viewProperty and contact flows)

- contactOwner(id)
  Purpose: Opens login popup if available (window.openLoginPopup), otherwise simulates contacting owner
  Used in: properties.html (card "تواصل" button)

- closePropertyModal (exposed as window.closePropertyModal)
  Purpose: Closes modal and cleans up listeners
  Used in: properties.html (modal close button and overlay click)

DOM IDs / selectors used in file:
- #navbar-container (injected nav)
- #popup-container (injected login popup)
- #footer-container (injected footer)
- #propertiesGrid (cards render target)
- #q, #city, #region, #type, #rooms, #min_price, #max_price (filter inputs)

Notes & Usage Patterns
- Many pages perform injection of `nav.html`, `login-popup.html`, and `footer.html` using fetch + DOMParser. After injection, scripts in those files are executed by recreating <script> elements.
- Global functions intentionally exposed on `window`: `openLoginPopup`, `closeLoginPopup`, `scrollToFooter`, `scrollToTop`, `scrollToServices`, `openEmail`, `bookProperty`, `changeSlide`, etc. These allow cross-file interactions after injection.
- Modal gallery variables are local to `showPropertyModal` but `closePropertyModal` is exposed for manual closing.
